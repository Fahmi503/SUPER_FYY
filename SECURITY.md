# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within SUPER FYY, please report it privately to the maintainers rather than creating a public issue.

Email: fahmi.firmansyah503@gmail.com

Please provide:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept code.
- Impact on local project isolation or secret redaction.

We take security seriously and will respond promptly to investigate and patch reported issues.
