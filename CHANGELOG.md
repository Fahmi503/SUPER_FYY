# Changelog

All notable changes to **SUPER FYY** are documented in this file.

## [1.0.0] - 2026-11-17

### Added
- **Core Memory Engine (P0-P2):** Multi-project registry, isolated SQLite stores, FTS5 full-text search, and automated key redaction.
- **Knowledge Graph Engine (P3):** 3D spherical topology computation, shortest-path calculation, and bidirectional impact analysis.
- **Model Context Protocol Server (P4):** Complete stdio-based MCP server exposing 16+ tools for autonomous agent interaction.
- **Multi-Agent Coordination (P5):** Role profile heuristics, resource lock conflict resolution, and execution contracts.
- **Dashboard & 3D Visualization (P6, M10.8):** WebGL spherical visualizer using Three.js and OrbitControls, featuring warm graphite theme and dynamic cluster aggregation.
- **Memory Intelligence (M10):** Context Capsule isolation, Decision Ledger with predecessor-successor links, stale memory hash checking, and handover summaries.
- **Deep Indexing Engine (M11):** Multi-language parser pipeline (Python AST, TypeScript/JavaScript regex-lexical, SQL DDL, Markdown) extracting comprehensive code entities.
- **Hierarchical & Semantic Discovery (M11.3):** Project Root anchor at `(0, 0, 0)`, differentiation between structural containment (`CONTAINS`) and functional dependencies (`CALLS`, `IMPORTS`, `MODIFIES`).
- **Synthetic Demo Workspace:** Self-contained `demo/quantum_flow` project demonstrating all system features out of the box.
